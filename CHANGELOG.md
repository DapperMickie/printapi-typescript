# Changelog

## 0.1.0

MIT-licensed package with npm, pnpm, Yarn Classic and Bun installation checks, a GitHub release tarball, and an OIDC npm publishing workflow.

Initial SDK covering the PrintAPI v2 contract retrieved on 2026-11-09. Includes all documented operations, generated component and path types, OAuth credentials and token providers, uploads, pagination, typed errors, cancellation, deadlines, safe GET retries, ESM/CommonJS packaging, and contract maintenance checks.
